# VibeDocs Notes (Android Kotlin + Jetpack Compose)

A clean, Google Docs-inspired Android notes app with live inline command styling.

## Supported Live Commands
- `# Heading 1`, `## Heading 2`, `### Heading 3`
- `*Italic*`
- `**Bold**`
- `***Bold & Italic***`
- `==Highlight==`
- `~~Strikethrough~~`
- `` `Inline Code` ``
- `- Bullet list`
- `- [ ] Checklist` & `- [x] Completed item`
- `> Blockquote`

## How to Compile to APK
1. **Via GitHub Actions (No PC required):** Create a new GitHub repository, upload all extracted files from this ZIP, open the **Actions** tab on GitHub, and download the compiled `VibeDocsNotes-debug-apk`.
2. **Via Android Studio / AndroidIDE:** Extract the ZIP and open the root folder directly.
